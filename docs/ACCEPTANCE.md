# Чеклист приёмки MVP

- [x] Сотрудник создаёт заявку (ряд, стол, категория, описание, шаблон, до 3 вложений)
- [x] Черновик сохраняется и отправляется
- [x] Статус по номеру и «последняя заявка»
- [x] Сотрудник отвечает в чате, получает уведомления о смене статуса
- [x] Админ входит по паролю, видит очередь в realtime (&lt; 1 с)
- [x] Взять в работу: гонка → 409 для второго
- [x] Решена → закрыта; отклонение с причиной; принудительное закрытие
- [x] Категории/шаблоны редактируются без релиза
- [x] Статистика: день/неделя/месяц/диапазон
- [x] Эскалация после N минут
- [x] Retention 45 дней (job)
- [x] HTTPS, привязка к LAN IP
- [x] Версия клиента &lt; min → блокировка
- [x] Smoke: `./scripts/smoke_test.sh 50` (в CI job `api`)

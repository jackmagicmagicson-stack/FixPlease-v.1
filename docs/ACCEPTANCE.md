# Чеклист приёмки MVP

- [ ] Сотрудник создаёт заявку (ряд, стол, категория, описание, шаблон, до 3 вложений)
- [ ] Черновик сохраняется и отправляется
- [ ] Статус по номеру и «последняя заявка»
- [ ] Сотрудник отвечает в чате, получает уведомления о смене статуса
- [ ] Админ входит по паролю, видит очередь в realtime (&lt; 1 с)
- [ ] Взять в работу: гонка → 409 для второго
- [ ] Решена → закрыта; отклонение с причиной; принудительное закрытие
- [ ] Категории/шаблоны редактируются без релиза
- [ ] Статистика: день/неделя/месяц/диапазон
- [ ] Эскалация после N минут
- [ ] Retention 45 дней (job)
- [ ] HTTPS, привязка к LAN IP
- [ ] Версия клиента &lt; min → блокировка
- [ ] Smoke: `./scripts/smoke_test.sh 50`

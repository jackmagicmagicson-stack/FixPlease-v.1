# Руководство администратора FixPlease

## Вход в кабинет

1. Откройте приложение → «Кабинет админа».
2. Введите пароль (задаётся при деплое сервера, см. `BOOTSTRAP_ADMIN_PASSWORD` в `deploy/.env`).
3. Сессия сохраняется до истечения токена или смены адреса сервера.

## Очередь

- Новые заявки отображаются в реальном времени.
- **Взять в работу** — только для статуса `new`; при одновременном нажатии побеждает первый (второй получит ошибку).
- **Решена** → **Закрыть** — стандартное завершение.
- **Отклонить** — обязательна причина (заявка → `closed`, тип `rejected`).
- **Закрыть принудительно** — из любого статуса.

## Эскалация

Если заявка в статусе `new` дольше N минут (по умолчанию 15), приходит уведомление всем админам. N меняется в **Настройки → Параметры очереди → Эскалация**.

## Категории и шаблоны

- Добавление категорий — только из кабинета админа (**Справочник**).
- Шаблоны привязаны к категории; сотрудник вставляет текст одним кликом.

## Статистика

Периоды: день, неделя, месяц, произвольный диапазон. Метрики: всего, открытые, закрытые, среднее время реакции, по категориям и админам.

## Retention

Заявки старше **45 дней** удаляются автоматически (вложения вместе с ними).

## Тихие часы

Настраиваются **локально на каждом компьютере** (Настройки → Уведомления). На сервер не синхронизируются.

## Версии и обновления клиента

- **Минимальная версия клиента** — в Настройках админа. Клиенты ниже этой версии блокируются при запуске.
- **Манифест обновления** — версия, URL установщика и подпись из `.sig` файла сборки. После сохранения клиенты могут нажать «Проверить обновления».
- Публичный ключ подписи встроен в установщик; приватный ключ храните только в CI/у IT.
